# Описание моделей данных (ORM Layer)

## Модуль: Inventory (Склад)
Данный модуль реализует раздел 2.2 технической спецификации.

### Таблица `components`
Центральный справочник электронных компонентов. 
- **Параметрический поиск**: Реализуется через поля `value`, `package`, `tolerance`. Это позволяет фильтровать компоненты для подбора аналогов.
- **Datasheets**: Поле `datasheet_path` хранит относительный путь к PDF-файлу на сервере.

### Таблица `stock`
Отражает текущее состояние остатков.
- **Логика резервов**: `actual_qty` (физика) vs `reserved_qty` (бронь). 
- **Бизнес-правило**: Списание происходит только из `actual_qty`, в то время как `reserved_qty` блокирует возможность создания новых заказов.

## Модуль: Production (Производство)
Реализует раздел 2.3 спецификации.

### Таблица `reservations`
Детализация каждой брони. Связывает `Order` и `Component`. 
- **Жизненный цикл**: Создается при старте заказа, удаляется при физическом списании со склада.
