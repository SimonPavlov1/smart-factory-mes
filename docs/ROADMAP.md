# Генеральный план разработки (Roadmap)
## Этап 1: Проектирование модели данных и API (Фундамент)

**Реализация структуры моделей (SQLAlchemy):** Определение сущностей 
`Component`, `Stock`, `Product`, `BOM`, `Order`.

**Конфигурация API (FastAPI):** Разработка эндпоинтов для первичного CRUD (Create, Read, Update, Delete) инвентаризации.

Инициализация БД: Настройка скриптов миграции и начального наполнения (Seed Data).

Этап 2: Слой бизнес-логики (Service Layer)

Сервис бронирования (ReservationService): Реализация алгоритма транзакционного списания ресурсов.
*

Валидация целостности данных: Проверка достаточности компонентов перед инициацией заказа.

Обработка исключений: Внедрение механизмов отката (rollback) при нехватке комплектующих.

Этап 3: Жизненный цикл производства (Workflow Control)

Управление статусами: Внедрение конечного автомата состояний (Finite State Machine) для заказов.

Списание ресурсов: Автоматизация вычета из actual_qty при завершении этапа производства.

Отслеживание партий: Логирование серийных номеров и связей с исходными компонентами.

Этап 4: Инфраструктура и Безопасность

Миграция на PostgreSQL: Переход с SQLite для обеспечения многопользовательской целостности.
*

Аутентификация: Внедрение JWT-токенов для разграничения прав доступа (RBAC).

Аудит: Создание лог-системы событий (кто, когда, какое действие произвел).

Этап 5: Аналитика и визуализация

Мониторинг: Создание отчетов по дефициту (Critical Stock Level).

KPI производства: Визуализация объема выпуска и эффективности использования ресурсов.
