# Спецификация программного интерфейса (API) Smart Factory MES

## 1. Общие сведения

Настоящий документ определяет протокол взаимодействия (REST API) между клиентским приложением и сервером управления производством (MES). Взаимодействие осуществляется по протоколу HTTP с передачей данных в формате JSON.

## 2. Справочник товарно-материальных ценностей (Inventory)

### 2.1. Получение списка компонентов

- **Метод:** `GET /components`
    
- **Описание:** Возвращает полный перечень номенклатурных позиций, зарегистрированных в системе.
    
- **Ответ (200 OK):**
    
    - Массив объектов типа `Component`, содержащий `id`, `name`, `part_number`, `category`.
        

### 2.2. Получение детали по идентификатору

- **Метод:** `GET /components/{id}`
    
- **Описание:** Запрос детальной информации о компоненте.
    
- **Параметры:** `id` (Integer, обязательный) — уникальный идентификатор записи.
    

---

## 3. Инженерные данные и спецификации (Production)

### 3.1. Реестр производимых изделий

- **Метод:** `GET /products`
    
- **Описание:** Возвращает реестр всех изделий (`ProductType`), доступных для производства.
    

### 3.2. Получение состава изделия (Bill of Materials)

- **Метод:** `GET /products/{product_id}/bom`
    
- **Описание:** Предоставляет спецификацию изделия, включая перечень компонентов, их количество и позиционные обозначения.
    
- **Логика:** Операция выполняет реляционное соединение таблиц `ProductType`, `ProductBOM` и `Component`.
    
- **Ответ:** Объект, содержащий наименование изделия, децимальный номер и массив `bill_of_materials` (с указанием `designator`, `quantity`, `component_name`, `part_number`).
    

---

## 4. Управление производственными заказами (Orders)

### 4.1. Регистрация производственного заказа

- **Метод:** `POST /orders`
    
- **Описание:** Создает запись о постановке изделия в план производства.
    
- **Тело запроса:**
    
    - `product_id` (Integer) — идентификатор изделия.
        
    - `target_qty` (Integer) — объем партии.
        
- **Ответ (201 Created):** Возвращает `order_id` и статус исполнения.
    

### 4.2. Получение статуса заказа

- **Метод:** `GET /orders/{id}/status`
    
- **Описание:** Возвращает текущий статус заказа (`New`, `In Progress`, `Done`, `Canceled`).
    

---

## 5. Складские операции (Stock)

### 5.1. Инвентаризация

- **Метод:** `GET /stock`
    
- **Описание:** Возвращает текущие остатки по номенклатурным позициям на складе.
