# API Спецификация системы управления производством

Данный документ описывает эндпоинты системы. API построено на базе **FastAPI**.

**Базовый URL:** `http://127.0.0.1:8000`

---

## 1. Inventory Management (Складской учет)

### 1.1 Получение списка компонентов
- **Метод:** `GET /components`
- **Описание:** Возвращает перечень всех компонентов. Поддерживает поиск через параметр `?search=...`.

### 1.2 Создание компонента
- **Метод:** `POST /components`
- **Описание:** Регистрация новой номенклатурной позиции.
- **Данные (JSON):** `name`, `part_number`, `category`, `package`, `value`, `voltage`, `specifications`.

### 1.3 Обновление компонента
- **Метод:** `PUT /components/{component_id}`
- **Описание:** Полное обновление параметров существующего компонента.

### 1.4 Удаление компонента
- **Метод:** `DELETE /components/{component_id}`
- **Описание:** Удаление компонента и связанных с ним остатков со склада.

### 1.5 Оприходование на склад (Приемка)
- **Метод:** `POST /incoming`
- **Параметры:** `component_id`, `quantity`, `location` (опционально).
- **Логика:** Увеличивает `actual_qty` в таблице `Stock`.

### 1.6 Корректировка остатка
- **Метод:** `PATCH /components/{component_id}/quantity`
- **Параметры:** `new_quantity` (float).
- **Логика:** Прямая установка нового значения остатка.

---

## 2. Production Engineering (Инжиниринг)

### 2.1 Получение списка изделий
- **Метод:** `GET /products`
- **Описание:** Возвращает структуру всех изделий с группировкой по категориям компонентов (Sections).

### 2.2 Создание структуры изделия
- **Метод:** `POST /setup-product`
- **Описание:** Атомарная загрузка дерева изделия (включая вложенные сборки).

### 2.3 Интеллектуальный маппинг BOM
- **Метод:** `POST /products/{product_id}/resolve-bom`
- **Описание:** Автоматическая привязка нераспределенных компонентов к базе склада.

---

## 3. BOM Management (Управление составом)

### 3.1 Обновление позиции в BOM
- **Метод:** `PUT /bom-items/{item_id}`
- **Описание:** Изменение количества, имени или ручная привязка ресурса (ID компонента).

### 3.2 Удаление позиции из BOM
- **Метод:** `DELETE /bom-items/{item_id}`
- **Описание:** Удаление строки из спецификации изделия.

---

## 4. Procurement (Снабжение)

### 4.1 Приемка закупки
- **Метод:** `POST /procurement/orders/{purchase_id}/receive`
- **Описание:** Подтверждение фактического прибытия товара.
- **Логика:** Меняет статус на `Received` и автоматически увеличивает `actual_qty` на складе для всех позиций в заказе.

---

## Коды ответов

| Код | Значение | Описание |
| :--- | :--- | :--- |
| **200** | OK | Запрос выполнен успешно. |
| **201** | Created | Ресурс успешно создан. |
| **400** | Bad Request | Ошибка валидации или дублирование данных. |
| **404** | Not Found | Ресурс не найден в базе данных. |
| **500** | Server Error | Внутренняя ошибка сервера (транзакция отменена). |
