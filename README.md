# Smart Factory MES

Система управления производством электроники с многоуровневым BOM, мягким резервированием и прослеживаемостью.

## Основные возможности
- **Параметрический учет**: Резисторы, конденсаторы и МС с учетом корпуса и допуска.
- **Мягкое резервирование**: Контроль остатков под конкретные заказы.
- **Traceability**: История сборки (кто паял, кто собирал, кто тестировал).
- **Документооборот**: Привязка PDF-чертежей к изделиям.

## Стек технологий
- Python 3.10+, FastAPI, SQLAlchemy, PostgreSQL.
